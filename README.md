# Excel Data Analysis

This repository contains a collection of data analysis projects developed using Microsoft Excel.

The projects cover different stages of the data analysis process, starting from raw datasets and moving through data cleaning and preparation, analysis, and visualization. Depending on the project, I use Excel formulas, PivotTables, PivotCharts, and other features to explore the data and answer specific questions.

The goal of this repository is to document my work with Excel and gradually build a collection of practical data analysis projects based on different datasets and scenarios.

## Projects

### Consultancy

This project focuses on the analysis of a consultancy dataset containing information about consultants, services, invoices, revenue, hourly rates, and payment status.

The analysis starts with cleaning and organizing the raw data to make it suitable for further analysis. PivotTables are then used to examine the data from different perspectives, such as consultant performance, revenue generated by services, hourly rates, and the status of invoices.

PivotCharts are also used to visualize the results and make comparisons between different categories and periods. Excel formulas are used alongside the PivotTables to answer specific questions and further analyze the results.

**Main topics covered:**
- Data cleaning and preparation
- Revenue and service analysis
- Consultant performance
- Hourly rate analysis
- Invoice payment status
- PivotTables
- PivotCharts
- Excel formulas

**File:** `Consultancy_dataset.xlsx`

### Global Superstore

This project analyzes the Global Superstore dataset using Microsoft Excel.

The dataset contains information about sales, products, customers, geographical areas, and other aspects of the business. The analysis focuses on organizing the data and using Excel tools to explore sales performance and identify relevant trends and patterns.

**Main topics covered:**
- Data cleaning and preparation
- Sales analysis
- Product and customer analysis
- Geographical analysis
- PivotTables
- PivotCharts
- Data visualization

**File:** `Global_superstore_dataset.xlsx`
